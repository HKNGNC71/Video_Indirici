How to get a cookies.txt file
  1. Install a Get cookies.txt LOCALLY extension for Chrome, Edge, or Firefox.
  2. Log in to YouTube or Instagram in that browser.
  3. Open the site, export its cookies with the extension, and save the file as cookies.txt.
  4. Upload the file above. Replace it any time the downloads start failing.

Cookies stay on your machine in this app's data folder and are only sent to the site you are downloading from.
